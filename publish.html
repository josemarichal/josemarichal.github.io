Three Ways to Turn Text into Blog Posts

⚡ Method 1: Drop into GitHub

Go to the blog_drafts/ folder in your GitHub repository and upload any .txt or .md file. A GitHub Action will automatically compile and publish it!

Upload to GitHub Drafts →

💻 Method 2: Local Python Tool

Run the script locally in your terminal. It handles formatting, updating the index, and pushing to GitHub in one command:

python publish_post.py my_essay.txt --push
